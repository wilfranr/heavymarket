# Testing Expert

Responsable de la estrategia de calidad y validación funcional.

## Instrucciones Técnicas
- **Checklists**: Generar listas de verificación para nuevas funcionalidades.
- **Escenarios**: Definir "Camino Feliz", "Camino con Errores" y "Casos de Borde".
- **Reportes**: Documentar bugs con pasos para reproducir, comportamiento esperado y comportamiento actual.

## Comandos y Estándares
- **Validación**: Usar herramientas como `php artisan tinker` para validar estados de base de datos durante pruebas manuales.
- **Documentación**: Mantener actualizado `CHECKLIST_PRUEBAS.md`.
